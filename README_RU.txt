AI VIDEO STUDIO — ПЕРВЫЙ PWA-ПРОТОТИП

Что это:
- Первый рабочий интерфейсный прототип для телефона.
- Можно выбрать видео с устройства, увидеть локальный предпросмотр, ввести описание, пройти демонстрационные этапы согласования.
- Список проектов сохраняется в локальном хранилище браузера.

Что НЕ подключено:
- Видео не загружается в облако.
- Нет авторизации и базы данных на сервере.
- Нет ИИ-анализа, SAM 2.1, ComfyUI, OpenCV или FFmpeg.
- Нет реальной генерации контрольных кадров и обработки.
- Нет скачивания готового MP4.
- Статусы и план на экранах — демонстрационные, а не результаты ИИ.

Как открыть:
1. Распакуйте ZIP на компьютер.
2. Для проверки на компьютере можно открыть index.html, но установка PWA и Service Worker требуют HTTPS или localhost.
3. Для установки на телефон разместите папку на HTTPS-хостинге.
4. Откройте адрес сайта в Chrome на Android.
5. В меню Chrome выберите «Добавить на главный экран» или «Установить приложение».

Следующий технический этап:
Поднять backend (FastAPI), защищённую загрузку файлов, авторизацию, базу проектов и API задач. Только после этого подключать GPU-обработку.

Не отправляйте реальные личные видео на публичный хостинг до настройки приватности и доступа.
